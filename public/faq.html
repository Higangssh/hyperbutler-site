FAQ

Docker on Windows, without WSL.

Common questions about running Docker on Windows 11 with hyperbutler, and how it compares with the other ways to do it.

How do I run Docker on Windows without WSL?

Install hyperbutler from the MSI, then:

hyperbutler start
docker run --rm hello-world
docker compose up -d

hyperbutler boots a small Linux VM directly through the Windows Host Compute Service (HCS, the Hyper-V API that WSL 2 itself uses) and runs Docker's own engine, dockerd and containerd, in it. The stock docker CLI and Docker Compose talk to it through a hyperbutler docker context. WSL can stay off, and its updates never touch the engine.

Does it work on Windows 11 Home?

Yes. Windows 11 Home, Pro and Enterprise on x64 are supported, with virtualization enabled in the firmware; the installer turns on Virtual Machine Platform if it is off. Windows 10 and Windows containers are not supported: hyperbutler runs Linux containers on Windows 11.

Do Docker Compose, VS Code and SDKs work?

Yes. They use the Docker API, which hyperbutler serves on a named pipe. Builds, healthchecks, service names, named volumes, bind mounts and published ports are tested end to end. Bind mounts from C:\ go through hyperbutler's own file server, and file watchers such as Vite and webpack see changes within milliseconds. What differs from Docker Desktop.

Do I need administrator rights?

Once, for the MSI. It installs a small broker service, the only privileged part, which starts and stops your VM from a fixed template. Daily use needs no admin rights and no Hyper-V Administrators membership.

Can I move from Docker Desktop?

hyperbutler import --from-desktop copies images and volumes over.

Can AI coding assistants use it?

hyperbutler mcp is an MCP server: an assistant in your editor can read status, containers, logs and disk use. Starting, stopping and deleting need flags you add, and what it may run is fenced in. MCP docs.

Is this Docker?

It runs Docker's own open-source engine and speaks the Docker API, so Docker's tools work with it. It is not made by Docker, Inc., and collects no telemetry.
